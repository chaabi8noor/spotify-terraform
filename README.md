# AI-Powered Spotify Playlist Generator with Terraform

This project demonstrates how to combine **Terraform**, **local AI**, and the **Spotify Terraform provider** to generate playlist recommendations from user preferences.

The project is designed as a DevOps/Infrastructure-as-Code portfolio project. It shows how Terraform can manage external services, how AI-generated data can be injected into Terraform variables, and how sensitive credentials can be handled safely.

---

## Project Overview

The goal of this project is to generate a Spotify-style playlist based on user input such as:

* Mood
* Music genres
* Energy level
* Styles to avoid
* Number of tracks

The playlist data is generated by a local AI model using **Ollama**, then passed to Terraform through an automatically generated variables file.

The project has two modes:

| Mode   | Description                                                          | Spotify Premium Needed                     |
| ------ | -------------------------------------------------------------------- | ------------------------------------------ |
| Mode 1 | Local AI generates playlist data and Terraform displays the output   | No                                         |
| Mode 2 | Terraform creates a real Spotify playlist using the Spotify provider | Yes, depending on Spotify API restrictions |

## Mode 1: AI Generation + Terraform Output

Mode 1 works without a Spotify Premium account.

It allows the user to enter playlist preferences in the terminal. A local AI model generates real song suggestions, and Terraform displays the generated playlist as output.

### Requirements for Mode 1

Install:

* Terraform
* Ollama
* VS Code
* PowerShell

Install the local AI model:

```powershell
ollama pull llama3.2
```

Test Ollama:

```powershell
ollama run llama3.2 "Generate 3 Spotify-style song recommendations"
```

---

## Running Mode 1

Run the script:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\generate_tracks.ps1
```

The script asks for user preferences:

```text
Playlist name:
Mood / vibe:
Genres:
Energy level:
What should the AI avoid?
Number of tracks:
```

Example input:

```text
Playlist name: DevOps Focus Mix
Mood / vibe: deep focus, coding, productive
Genres: electronic, lo-fi, ambient techno
Energy level: medium
What should the AI avoid? vocals, sad acoustic
Number of tracks: 10
```

The script generates:

```text
generated.auto.tfvars.json
```

Terraform automatically loads files ending with:

```text
.auto.tfvars.json
```

Then run:

```powershell
terraform fmt
terraform validate
terraform plan
```

Expected result:

```text
Success! The configuration is valid.
```

Terraform should display the generated playlist in the output.

## Mode 2: Real Spotify Playlist Creation

Mode 2 connects Terraform to Spotify and attempts to create a real playlist.

This mode uses the community Spotify Terraform provider:

```hcl
terraform {
  required_providers {
    spotify = {
      source  = "conradludgate/spotify"
      version = "0.2.7"
    }
  }
}
```

The provider can search Spotify tracks and create a playlist from the AI-generated recommendations.

---

## Spotify API Limitation

Spotify may require the owner of the Spotify Developer app to have an active Spotify Premium subscription.

Without Premium, Terraform may fail with an error similar to:

```text
Active premium subscription required for the owner of the app
```

This is not a Terraform code error. It is a Spotify API access restriction.

For this reason, the project supports:

```text
Mode 1: fully working local AI + Terraform demo
Mode 2: real Spotify integration when API access is available
```

## Environment Variables

Secrets must never be committed to GitHub.

Create a local `.env` file:

```env
SPOTIFY_CLIENT_ID=your_client_id_here
SPOTIFY_CLIENT_SECRET=your_client_secret_here
SPOTIFY_PROXY_BASE_URI=http://127.0.0.1:27228
```

Create a local `terraform.tfvars` file:

```hcl
spotify_api_key = "your_spotify_api_key_here"
```

Use the example files for GitHub:

```text
.env.example
terraform.tfvars.example
```
